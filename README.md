# Mend: propuesta de identidad

Presentación de la primera propuesta de identidad de Mend (versión 2, 29 de septiembre de 2026), mostrada en la reunión de seguimiento del proyecto de título, Escuela de Diseño UC.

Se abre en el navegador. Atajos: flechas para navegar, I índice, N notas del orador, F pantalla completa.

La tipografía es Neue Haas Grotesk Display Pro si está instalada en el equipo; si no, cae a Helvetica Neue.
